# m-calc —— 计算器（移动端）

手机计算器：大显示屏 + 4×5 按钮网格。支持四则运算、百分比、正负号、
小数、连续运算（`3 + 5 × 2 =` 按输入序求值）。

## 运行

```bash
go build -o /tmp/gox-current ./cmd/gox
/tmp/gox-current apps/m-calc/src/main.js
```

## 压到的能力

- **`grid` 布局**：按钮盘用 `grid columns={4}`，等宽填满；
- **拇指热区尺寸**：每个按钮 88×64，移动端最小触控目标之上；
- **计算引擎是纯函数**（`lib/calc.js`）：按键序列 → 显示值，
  状态机不碰 UI，可脱离界面单测；
- **键盘等价**：桌面调试时数字键 / `+-*/=` / `Enter` / `Esc` 同样可用。

## 结构

```
src/
  main.js        入口（window 390×720）
  app.js         根组件：显示屏 + 按钮网格
  store.js       signal：显示值 / 按键分发
  theme.js       设计令牌
  lib/calc.js    纯逻辑：按键状态机（数字/运算符/求值/清除）
```

## 已知限制

- 连续运算按**输入顺序**求值（与 iOS 计算器一致），不做优先级；
- 科学计算（sin/cos/…）留待横屏模式，v1 只做竖屏。
